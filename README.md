MediKiosk – AI-Based Patient Case-Taking Software
Java, Spring Boot, MySQL, HTML, CSS, JavaScript, Gemini API, REST API, Git & GitHub

- Developing an AI-based system for collecting and organizing patient medical history before consultation.
- Integrated Gemini API for symptom-based follow-up questions, medical document analysis, and structured summary generation.
- Developed backend services using Java/Spring Boot and designed database integration using MySQL.
- Built a workflow connecting patient input, AI processing, medical information storage, and doctor review.
